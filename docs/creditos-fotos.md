# Créditos de fotos — Mezzanine

## Fotos propias del restaurante

Las fotos de `client/public/photos/` sin carpeta (`venue-*`, `food-*`, `drinks-*`) vienen del Instagram oficial **@mezzaninerooftop**. Ver `docs/datos-pendientes.md`, sección 8.

## Fotos de stock (Unsplash)

Las 48 imágenes de `client/public/photos/menu/` son fotos **genéricas** de [Unsplash](https://unsplash.com), descargadas el 16-nov-2026. Se usan de forma provisional para los platos y bebidas que todavía no tienen foto propia.

- **Licencia:** [Unsplash License](https://unsplash.com/license). Permite el uso comercial gratis y no exige atribución, aunque se agradece. Se descartaron las fotos Unsplash+ (de pago) y las que mostraban personas o marcas visibles.
- **No son los platos reales de Mezzanine.** La página Eat avisa de que las imágenes son ilustrativas. Conviene sustituirlas por fotos propias en cuanto existan: basta con reemplazar el archivo con el mismo nombre y ejecutar `npm run db:seed`.
- **Para retirar una foto:** borra su archivo de `client/public/photos/menu/` y ejecuta `npm run db:seed`. El plato volverá a mostrar su ilustración SVG.
